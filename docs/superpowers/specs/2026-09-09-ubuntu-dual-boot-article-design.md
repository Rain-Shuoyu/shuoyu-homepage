# Ubuntu 双系统文章改写与发布设计

## 目标

把《为 Windows 电脑安装 Ubuntu》改写成一篇可直接发布到 `blog.shuoyu.me` 的中文实操指南。文章只覆盖保留 Windows、安装 Ubuntu 双系统的场景，不介绍清除 Windows 的单系统安装。

## 内容结构

文章按实际操作顺序组织：

1. 适用范围和风险说明
2. 安装前准备与完整备份
3. 检查 BitLocker，并保存恢复密钥
4. 从 Windows 分出未分配空间
5. 使用 Rufus 制作 Ubuntu 启动盘
6. 从电脑的 UEFI 启动菜单进入 Ubuntu 安装环境
7. 选择与 Windows Boot Manager 共存并完成安装
8. 首次启动及常见注意事项

## 编辑原则

- 保留原稿的亲身实践语气，但去掉重复警告、口语赘述和不必要的感叹号。
- 不把特定电脑上的现象写成通用规则。例如，启动菜单快捷键可能是 F12、F9、Esc 或其他按键。
- 不要求用户强行覆盖 Rufus 自动选择的文件系统、簇大小或写入参数，除非官方流程明确要求。
- 将 200 GB 改为示例容量，并说明读者应按用途和剩余空间决定实际大小。
- 明确区分“关闭 BitLocker”和“保存恢复密钥”，不声称两者在所有安装场景下都绝对必要。
- 如果安装器没有显示“与 Windows Boot Manager 共存”，要求读者停止操作，而不是贸然选择“擦除磁盘”或自行分区。
- 外部链接优先使用 Ubuntu、Microsoft、Rufus 和电脑厂商的官方资料。

## 博客接入

新增一篇符合现有 Astro 内容集合规范的 Markdown 文章，类型为 `engineering`，包含中文标题、摘要、发布日期、标签和 `draft: false`。不修改博客布局或其他文章，也不触碰工作区中已有的未提交改动。

## 验证

- 对照当前官方文档核查关键安装步骤和风险提示。
- 检查文章中的链接、标题层级、代码与警告块格式。
- 运行博客内容测试、类型检查和生产构建。
- 检查生成页面中标题、目录、列表和外链是否正常。

## 发布边界

本次“发布”指把文章作为公开内容加入博客源码并确保生产构建通过。除非用户另行要求，不执行 Git 推送或线上部署。
