# shuoyu.me 个人主页设计

## 1. 目标与定位

这是一个面向公开访问的静态个人主页，服务于三种阅读场景：

- 面试官和潜在合作伙伴快速判断 Shuoyu Chen 的研究方向、项目经验与合作可靠性。
- 同事了解当前研究重点、代表性成果和可讨论的技术主题。
- 同学、学弟学妹感受到个人的好奇心、动手能力和不止于科研的兴趣。

核心定位是：**一名认真做研究、也喜欢把想法做成小项目的计算机专业大学生。**

研究内容是首页主叙事；小项目作为轻量的 Lab 区域出现，不与研究项目争夺首屏注意力。

## 2. 已确认的设计方向

### 页面结构

采用 `Split index`：

- 左栏固定个人身份和一句核心表达。
- 右栏纵向浏览当前状态、研究项目与 Lab 项目。
- 桌面端保持左右分栏；移动端改为上下排列，左栏内容移动到顶部。
- 项目使用带分隔线的文字索引行，不使用卡片墙、瀑布流或纯卡片堆叠。

### 视觉风格

采用 `Graphite & Cobalt`：

- 背景使用近白色和浅灰色，营造清晰、安静的阅读环境。
- 主要文字使用深石墨色，辅助文字使用冷灰蓝。
- 钴蓝仅用于链接、年份、状态和轻量 hover 反馈。
- 采用清楚的无衬线排版，标题有足够尺寸和留白，但不追求夸张的视觉效果。
- 页面整体更像研究者的在线档案，而不是作品集模板或营销落地页。

### 文案气质

- 具体、短句、少形容词。
- 说明正在研究什么、做过什么、如何联系，不使用夸大性的自我评价。
- 通过“正在探索”和 Lab 项目自然体现趣味与个人性，不依赖装饰性文案。

## 3. 信息架构

页面导航仅包含三个锚点：`Research`、`Lab`、`About`。

### Intro / Now

首屏左侧包含：

- Shuoyu Chen
- Sun Yat-sen University / iSEE Lab
- Undergraduate researcher
- 一句概括性定位，表达具身智能、灵巧操作和计算机视觉方向
- GitHub、邮箱等联系入口

首屏右侧包含：

- `NOW / 2026` 状态标签
- 当前研究方向的简短描述
- 研究主题关键词：Embodied Intelligence、Dexterous Manipulation、Computer Vision

### Research

研究项目作为页面主体，第一版优先展示：

1. OmniDexGrasp（ICRA 2026）
2. BiDexGrasp
3. DynamicManip

每个项目使用一行索引，包含项目名称、会议或项目标签、简短描述和外部链接。只有已经从公开资料或用户补充信息中确认的贡献角色、论文信息和指标才会写入页面。

### Lab / Side Projects

小项目放在研究区域之后，使用轻量的文字列表或分组索引。首版可选项目来自公开 GitHub 仓库：

- DeepSneak：DeepSeek Harness 插件
- TruthForge：多智能体事实核查系统
- PolyGo：协作式旅行规划 Web 应用
- AfterGlow：反思日记工具
- NeuralBlock：神经网络结构可视化工具

Lab 区域不需要完整展开每个项目的技术细节，只展示项目名、类别、技术关键词和 GitHub 链接；访问者可以通过外链继续深入。

### About / Contact

包含简短经历、学校与实验室信息、GitHub、公开邮箱和其他已经确认的链接。暂不放置未准备好的简历下载入口，也不创建空的社交媒体按钮。

## 4. 技术架构

使用 Astro、TypeScript 和原生 CSS，生成纯静态站点。

### 组件边界

- `SiteShell`：全局页面容器、背景、基础排版和响应式断点。
- `SideIdentity`：左栏姓名、身份、当前状态和联系链接。
- `SectionNav`：Research、Lab、About 锚点导航。
- `NowSection`：当前研究状态与方向关键词。
- `ResearchList`：研究项目索引列表。
- `LabList`：小项目轻量索引列表。
- `AboutSection`：个人简介和联系信息。
- `ExternalLink`：统一处理外部链接、箭头标识和无障碍标签。

项目内容集中在本地数据文件或 Astro Content Collection 中，组件只负责展示，不在组件内部硬编码项目详情。

### 数据流

本地内容文件 → Astro 构建时读取 → 生成 HTML → Cloudflare Pages 发布静态产物。

运行时不依赖数据库、API、登录状态或第三方脚本。GitHub 等外部链接只作为用户点击后的跳转目标，不参与首屏渲染。

### 部署

- 构建命令：`npm run build`
- 发布目录：`dist`
- 目标平台：Cloudflare Pages；也兼容将静态产物部署到 Cloudflare Workers 静态资源配置。
- 域名 `shuoyu.me` 审核完成后再配置自定义域名和 DNS，不影响本地开发与预览。

## 5. 响应式与交互

- 桌面端使用左右分栏，左栏在滚动时保持可见。
- 窄屏设备将左栏移动到顶部，取消固定定位，避免挤压正文。
- 研究与 Lab 项目使用 hover 下划线、链接颜色和箭头变化提供反馈。
- 不使用需要后端支持的动态功能，不使用复杂动画或滚动劫持。
- 所有内容都应在没有 JavaScript 的情况下可阅读；JavaScript 只用于必要的移动端菜单等增强行为。

## 6. 可访问性、SEO 与错误处理

- 使用语义化的 `header`、`nav`、`main`、`section`、`footer` 和标题层级。
- 外部链接提供清晰的链接文本、键盘焦点状态和必要的 `aria-label`。
- 颜色对比度满足正常阅读要求，钴蓝不承担唯一的信息表达职责。
- 页面提供 title、description、Open Graph 基础信息和 canonical URL；域名确定后填入正式 canonical。
- 图片如果不是必要内容就不作为首屏依赖；需要图片时使用本地优化资源和明确的替代文本。
- 项目外链失效时，页面仍显示项目名称和描述，不让外链错误阻塞其他内容。
- 缺少可选字段时隐藏该字段，而不是显示空标签、假链接或占位文本。

## 7. 验证计划

实现完成后至少验证：

1. Astro 生产构建成功，`dist` 中生成首页和静态资源。
2. 桌面宽屏、平板宽度和手机宽度下无横向溢出，左右分栏能够正常折叠。
3. 键盘可以访问所有导航和外部链接，焦点状态清晰。
4. Research、Lab、About 锚点滚动到正确位置。
5. 所有公开项目链接可访问，链接文本与目标项目对应。
6. 无 JavaScript 时正文仍可阅读。
7. Cloudflare Pages 预览环境可以完成构建并正确提供静态资源。

## 8. 非目标

首版不包含：

- 后台管理、数据库、登录和动态博客系统
- 项目评论、点赞、访客统计或复杂分析
- 大量动画、3D 场景或重型视觉素材
- 研究项目的虚构贡献、未经确认的论文状态或未经核实的数据
